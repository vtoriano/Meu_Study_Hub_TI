# Como colaborar

Obrigado pelo interesse no PortfolioHUB. Este repositório é um portfólio acadêmico, mas aceita sugestões e correções.

## Fluxo de colaboração

1. Abra uma **issue** descrevendo a sugestão ou o problema.
2. Crie uma **branch** a partir da `main`, com um nome claro (por exemplo, `docs/corrige-readme-bd`).
3. Faça as alterações e envie com **commits** descritivos.
4. Abra um **pull request** explicando o que mudou e por quê.
5. O responsável revisa e faz o merge na `main`.

A branch `main` é protegida: não se altera diretamente.

## Padrão de commits

Use o formato `tipo: descrição curta`, por exemplo:

- `docs: atualiza README de Banco de Dados I`
- `feat: adiciona projeto de Business Intelligence`
- `fix: corrige link quebrado na página`
- `security: atualiza política de segurança`

## Padrão de pastas

- Disciplinas ficam em `02_Disciplinas_Atuais/<Disciplina>/`, com `Atividades_e_Entregas/` e `Anotacoes_e_Resumos/`.
- Projetos ficam em `03_Projetos_e_Certificados/<Projeto>/`, cada um com seu `README.md`.
- Documentação da implantação fica em `docs/`.

## Conduta

Seja respeitoso e objetivo nas issues e revisões. Não publique dados pessoais de terceiros.
