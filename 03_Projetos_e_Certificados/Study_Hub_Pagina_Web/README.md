# Study Hub — Página Web

Página web estática do portfólio, publicada com **GitHub Pages**.

- **Versão atual:** 1.0
- **Página publicada:** https://vtoriano.github.io/Meu_Study_Hub_TI/
- **Código:** `index.html` e `assets/css/style.css` na raiz do repositório (o GitHub Pages serve a partir da raiz da branch `main`).

## Objetivo

Apresentar meu perfil, meus interesses em Dados e IA, as disciplinas do módulo e os projetos do Study Hub em um só lugar, de forma pública e fácil de compartilhar.

## Tecnologias

- HTML5
- CSS3 (layout responsivo, com tema claro e escuro automático)
- Git e GitHub
- GitHub Pages

## Seções da página

1. Início
2. Sobre mim
3. Interesses e carreira
4. Disciplinas do módulo
5. Projetos e documentos
6. Contato

## Como visualizar localmente

1. Clone o repositório: `git clone https://github.com/vtoriano/Meu_Study_Hub_TI.git`
2. Abra o arquivo `index.html` no navegador.
