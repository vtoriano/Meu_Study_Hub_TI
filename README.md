# Meu Study Hub TI

Repositório de estudos e portfólio de **Vitor Pupe Brasil Vilaverde**, estudante de **Ciência de Dados e Machine Learning** no UniCEUB (Turma A).

O Study Hub organiza minha jornada de aprendizado em **Dados e Inteligência Artificial**, documentando minha evolução prática desde o início do curso.

**Página publicada (GitHub Pages):** https://vtoriano.github.io/Meu_Study_Hub_TI/

## Estrutura do repositório

```text
Meu_Study_Hub_TI/
├── index.html                      # Página inicial (GitHub Pages)
├── assets/
│   └── css/style.css               # Estilos da página
├── README.md                       # Este arquivo
├── 01_Apresentacao_e_Perfil/       # Perfil pessoal e contato
├── 02_Disciplinas_Atuais/          # Uma pasta por disciplina do módulo
│   ├── Bootcamp_I/
│   ├── Banco_de_Dados_I/
│   ├── Business_Intelligence_I/
│   ├── Calculo_para_Computacao/
│   ├── Desenvolvimento_para_Ciencia_de_Dados_I/
│   └── Fundamentos_de_Seguranca_Cibernetica/
└── 03_Projetos_e_Certificados/     # Projetos e certificados
    └── Study_Hub_Pagina_Web/       # Projeto 1: esta página (v1.0)
```

Cada disciplina contém as subpastas `Atividades_e_Entregas/` e `Anotacoes_e_Resumos/`.
